# المحاضرات والملفات الدراسية

صفحة إعدادية الفرابي المهنية الأهلية. ملفات الموقع ثابتة وتعمل على GitHub Pages.

## رفع PDF من GitHub

1. افتح مجلد المادة داخل `files/`، ثم افتح `chapter-01/` للمحاضرة أو `month-01-exam/` للامتحان.
2. اختر **Add file → Upload files**. ارفع ملف PDF واحفظه عبر **Commit changes**.
3. افتح `content.json` واضغط زر القلم للتعديل. في المادة المطلوبة، أضف رقم المحاضرة وعنوانها ومسار الملف داخل `lectures`، أو حدّث `exam.questions` للأسئلة و`exam.answers` للأجوبة. إذا رفعت الملف باسم ومسار مطابقين لما في الإعدادات، سيظهر زر التحميل تلقائياً.

| المادة | المجلد داخل `files/` |
| --- | --- |
| تجميع الحاسوب | `computer-assembly` |
| مبادئ الاتصالات والشبكات | `communications-networks` |
| تطبيقات الحاسوب | `computer-applications` |
| مبادئ الحاسوب الأساسية | `computer-fundamentals` |

مثال على عنصر محاضرة داخل `lectures`:

```json
{
  "number": 2,
  "title": "مكوّنات الحاسوب",
  "pdf": "files/computer-assembly/chapter-01/lecture-02.pdf"
}
```

لإضافة الفصل الثاني، أنشئ `chapter-02/` داخل مجلد المادة وأضف عنصراً داخل `chapters` برقم `2` وعنوان `الفصل الثاني` وقائمة `lectures`. رتّب المحاضرات والفصول عبر القيمة الرقمية `number`. يجب أن يطابق مسار كل ملف اسمه وحالة أحرفه في GitHub.

## الدرجات

حقلا كل مادة للروابط هما `grades.monthOne` و`grades.chapterOne`. ضع رابط HTTPS لبوابة المدرسة بعد تفعيل تسجيل الدخول والتحقق من صلاحيات الطالب في الخدمة نفسها. اختبر بحسابي طالبين للتأكد من أن كل حساب يرى درجته وحدها. احفظ أسماء الطلاب والدرجات والملفات داخل الخدمة الخاصة. اترك الحقل `null` إذا كانت البوابة غير متاحة.

## المعاينة والنشر

للمعاينة محلياً، شغّل `python -m http.server 8000` من مجلد الصفحة وافتح `http://localhost:8000/`.

بعد اعتماد التصميم، ارفع محتويات الحزمة إلى جذر المستودع العام، بما فيها `.nojekyll`. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط **Save**. تظهر وصلة الموقع في صفحة إعدادات Pages بعد اكتمال النشر. [دليل GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
